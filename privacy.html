施行日: 2026-10-25

このポリシーは、個人利用のアプリ「bingx-rclone」と、このウェブサイトに適用されます。運営者は個人です。

アクセスするデータ

bingx-rclone が要求する Google API のスコープは、次の 1 つだけです。

https://www.googleapis.com/auth/drive.file

drive.file でアクセスできるのは、このアプリ自身が作成したファイル、および利用者がこのアプリで開いたファイルに限られます。実際に扱うのは、所有者本人のサーバー上にある暗号資産取引用ボットのログとコードのうち、所有者本人の Google ドライブ内 BingX_bot フォルダへ作成・更新するファイルです。

次のものにはアクセスしません。

  • Google ドライブ全体の一覧、およびほかのアプリが作成したファイル
  • Gmail、Google カレンダー、連絡先
  • 所有者以外の Google アカウントのデータ

このウェブサイトは静的な HTML です。フォーム、アカウント登録、訪問者からのデータ受信はありません。

利用目的

Google API から受け取ったデータは、所有者本人のファイルを、所有者本人の Google ドライブへ同期するためだけに使います。

  • 所有者本人のサーバーから、所有者本人の Google ドライブ内 BingX_bot フォルダへ、ログとコードをアップロードする
  • 同じファイルの更新を、同じフォルダへ一方向に同期する（ドライブからサーバーへは書き戻さない）

広告、プロファイリング、信用判断、販売、第三者への提供には使いません。開発者が内容を読むための仕組みはありません。ファイルを見ることができるのは、自分のドライブを開く所有者本人だけです。

Google API Services User Data Policy（限定的な利用）

bingx-rclone は、Google API から受け取った情報の利用、およびその情報の他のアプリへの転送について、Google API Services User Data Policy を遵守します。Limited Use（限定的な利用）の要件も含まれます。

bingx-rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

限定的な利用として、次を守ります。

  • Google ユーザーデータは、このアプリの機能として明示している「所有者本人のファイルを、所有者本人の Google ドライブへ同期する」目的にのみ使います。
  • 広告の配信、リターゲティング、パーソナライズド広告、興味関心に基づく広告には使いません。信用力の判定や貸付にも使いません。
  • データを販売しません。広告事業者、データブローカー、情報の再販者、その他の第三者へ譲渡しません。
  • 人間がユーザーデータを読むことはありません。例外は、所有者本人が自分のファイルを自分で確認する場合だけです。
  • セキュリティ、適用される法令の遵守、または所有者本人の同意がある場合を除き、データを転送しません。このアプリはデータを第三者と共有しません。

共有、販売、第三者

データを収集して別の場所へ蓄積することはありません。販売しません。共有しません。第三者へ提供しません。ファイルが移動する先は、所有者本人の Google ドライブだけです。解析サービスや広告ネットワークへは送りません。

保存場所

  • 同期先: 所有者本人の Google ドライブ内の BingX_bot フォルダ
  • 同期元: 所有者本人のサーバー（rclone が動作している環境）
  • このウェブサイト: 静的ファイルのみ。データベースはありません。

Google ユーザーデータを受け取る開発者運営のサーバーはありません。Cookie は使いません。アクセス解析も使いません。外部のトラッキング用スクリプトは読み込みません。

保持と削除

ファイルをどれだけ残すかは、所有者本人が決めます。

  • このアプリに付与した Google アカウントのアクセス権は、https://myaccount.google.com/permissions でいつでも取り消せます。
  • Google ドライブ上のファイルは、所有者が Google ドライブから削除できます。
  • サーバー上の元ファイルも、所有者が削除できます。

アクセス権を取り消すと、このアプリは以後 Google ドライブへアクセスできなくなります。すでにドライブへ保存されたファイルは、所有者が削除するまで、所有者のドライブに残ります。

このツール

このアプリは外部の利用者がいない個人用ツールです。アクセス権は https://myaccount.google.com/permissions で取り消せます。

変更

このポリシーを変えるときは、このページを更新し、施行日を改めます。

Privacy Policy

Effective date: 2026-10-25

This policy applies to bingx-rclone, an app maintained for personal use, and to this website. The operator is an individual.

Data accessed

bingx-rclone requests one Google API scope:

https://www.googleapis.com/auth/drive.file

drive.file allows access only to files created by the app itself and files the user opens with the app. The files in use are the owner's own crypto trading bot logs and code, created or updated in the BingX_bot folder in the owner's own Google Drive.

The app does not access:

  • A listing of the whole of Google Drive, or files created by other apps
  • Gmail, Google Calendar, or contacts
  • Data in any Google account other than the owner's

This website is static HTML. It has no forms, no accounts, and it receives no data from visitors.

How data is used

Data received from Google APIs is used only to sync the owner's own files to the owner's own Google Drive.

  • Upload the owner's logs and code from the owner's server into the BingX_bot folder in the owner's Google Drive
  • Sync later updates of those same files one way into that same folder (nothing is written back from Drive to the server)

The data is not used for advertising, profiling, credit decisions, sale, or disclosure to any third party. There is no facility for a developer to read the contents. The only person who can view the files is the owner, in the owner's own Drive.

Google API Services User Data Policy, including Limited Use

bingx-rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

bingx-rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Under those Limited Use requirements:

  • Google user data is used only to provide the feature shown by this app: syncing the owner's own files to the owner's own Google Drive.
  • It is not used to serve ads, including retargeting, personalized, or interest-based advertising. It is not used to determine credit-worthiness or for lending.
  • It is not sold, and it is not transferred to advertising platforms, data brokers, information resellers, or any other third party.
  • Humans do not read the user data, except the owner viewing the owner's own files.
  • The data is not transferred except where required for security, to comply with applicable law, or with the owner's consent. This app does not share data with third parties.

No sharing, no selling, no third parties

The app does not collect data into a separate store. It does not sell data. It does not share data. It does not provide data to third parties. The only destination of a file is the owner's own Google Drive. Nothing is sent to an analytics service or an advertising network.

Storage

  • Destination: the BingX_bot folder in the owner's own Google Drive
  • Source: the owner's own server, where rclone runs
  • This website: static files only, with no database

There is no developer-operated server that receives Google user data. The site uses no cookies and no analytics, and it loads no third-party tracking scripts.

Retention and deletion

How long files are kept is decided by the owner.

  • Access granted to this app can be revoked at any time at https://myaccount.google.com/permissions.
  • Files in Google Drive can be deleted by the owner from Google Drive.
  • The original files on the owner's server can be deleted by the owner.

After access is revoked, the app can no longer reach Google Drive. Files already stored in Drive remain in the owner's Drive until the owner deletes them.

This tool

This is a personal tool with no external users. Access can be revoked at https://myaccount.google.com/permissions.
