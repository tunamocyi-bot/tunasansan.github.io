個人用デスクトップ OAuth クライアント

bingx-rclone

ホーム プライバシーポリシー 利用規約 English

所有者本人の rclone から、所有者本人の Google ドライブへファイルを送るためだけのアプリです。

このアプリについて

bingx-rclone は、所有者本人のサーバーで動かしている暗号資産取引用ボットのログとコードを、自分の Google ドライブ内の BingX_bot フォルダへアップロードし、同期するためのアプリです。同期はサーバーからドライブへの一方向です。使うのは所有者本人の rclone だけで、ほかの利用者はいません。

アクセスする範囲

使用する Google API のスコープは、次の 1 つだけです。

https://www.googleapis.com/auth/drive.file

drive.file で扱えるのは、このアプリ自身が作成したファイル、および利用者がこのアプリで開いたファイルに限られます。このアプリが実際に作成・更新するのは、所有者本人の BingX_bot フォルダに置くログとコードです。Google ドライブ全体の一覧、ほかのアプリが作ったファイル、Gmail、カレンダー、連絡先にはアクセスしません。

利用者

利用者は所有者本人だけです。個人利用であり、商用サービスではなく、第三者がログインするアプリでもありません。認可するのは所有者本人の Google アカウントだけです。

データの扱い

データを収集・販売・共有しません。アナリティクスも Cookie も使いません。ファイルの送り先は所有者本人の Google ドライブだけで、それ以外の場所へは送りません。開発者用の別サーバーが Google のデータを受け取ることはありません。

詳細は プライバシーポリシー に、利用条件は 利用規約 に書いてあります。

English

What this app is

bingx-rclone is a desktop OAuth client used only by the owner's own rclone instance. It uploads and syncs the owner's own crypto trading bot logs and code from the owner's own server into a BingX_bot folder in the owner's own Google Drive. The sync is one-way, from the server to Drive. There are no other users.

What it accesses

The app requests a single Google API scope:

https://www.googleapis.com/auth/drive.file

drive.file covers only files created by the app itself, and files the user opens with the app. In this use, those files are the owner's logs and code written into the owner's BingX_bot folder. The app does not list the rest of Google Drive, and it does not access files created by other apps, Gmail, Calendar, or contacts.

Who uses it

The only user is the owner. This is personal use. It is not a commercial service, and no one else signs in. The only Google account that authorizes the app is the owner's.

How data is handled

The app does not collect, sell, or share data. It uses no analytics and no cookies. Files are sent only to the owner's own Google Drive and nowhere else. No separate developer server receives Google user data.
